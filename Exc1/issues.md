# Проблемы текущей архитектуры и их приоритизация

1. Невозможность быстро подключить данные новой компании

На первом месте в списке, т.к. компания планирует скоро покупать новые компании, а данные оттуда очень важны

2. Персональные и медицинские данные на витринах

На втором месте в списке, т.к. нужно как можно раньше их убрать из витрины, чтобы избежать утечек.

3. Использование Microsoft SQL

По новому законодательству нельзя использовать иностранное ПО для критический областей (банкинг, медицина). К тому же текущая версия очень старая и может не иметь исправление критических уязвимостей.

4. Использование Microsoft Power BI

По новому законодательству нельзя использовать иностранное ПО для критический областей (банкинг, медицина).

5. Перегруженная монолитная база

Разработка новых фичей происходит очень долго.

6. Перемешенные домены

В текущем решении сложно понять границы домена.
